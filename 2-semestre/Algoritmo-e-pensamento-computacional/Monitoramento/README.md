# Monitoramento em C

Atividade desenvolvida para a disciplina de **Algoritmos e Pensamento Computacional**, utilizando a linguagem **C**.

## 📋 Sobre a atividade

O objetivo desta atividade é desenvolver um programa de monitoramento utilizando estruturas de repetição, trabalhando conceitos fundamentais de programação em linguagem C.

O projeto utiliza obrigatoriamente uma das seguintes estruturas de repetição:

* `while`
* `do...while`
* combinação entre as duas

## 💻 Tecnologias utilizadas

* Linguagem C
* Visual Studio Code
* Git e GitHub

## 📁 Arquivo

```text
monitoramento.c
```

## ▶️ Como executar

Compile o código utilizando um compilador de C.

Exemplo utilizando o GCC:

```bash
gcc monitoramento.c -o monitoramento
```

Depois, execute:

### Windows

```bash
monitoramento.exe
```

### Linux / macOS

```bash
./monitoramento
```

* Linguagem C

* Entrada e saída de dados
