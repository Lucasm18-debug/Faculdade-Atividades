# Atividade - Vetor

Atividade desenvolvida na disciplina de **Algoritmo e Pensamento Computacional**, utilizando a linguagem C.

## Objetivo

Criar um programa capaz de ler 20 números inteiros e armazená-los em um vetor, realizando diferentes operações sobre os valores armazenados.

## Requisitos da atividade

O programa deve:

- Ler 20 números inteiros e armazená-los em um vetor;
- Calcular e exibir a soma dos elementos que são múltiplos de 3;
- Calcular e exibir a média dos elementos pares;
- Informar a quantidade de números negativos;
- Informar a quantidade de números pares;
- Determinar o maior valor do vetor;
- Determinar o menor valor do vetor;
- Exibir todos os elementos do vetor.

## Conceitos utilizados

- Vetores;
- Laço de repetição `for`;
- Estruturas condicionais `if` e `else`;
- Operador de resto `%`;
- Contadores;
- Acumuladores;
- Entrada de dados com `scanf`;
- Saída de dados com `printf`.

## Arquivos

- `vetor.c` — código-fonte da atividade.

## Funcionamento

O programa percorre as 20 posições do vetor utilizando um laço `for`. Durante a leitura dos valores, verifica se cada número é múltiplo de 3, par ou negativo, realizando as respectivas somas e contagens.

Para encontrar o maior e o menor valor, o primeiro elemento do vetor é utilizado como referência inicial e os demais elementos são comparados com ele.

Ao final, o programa apresenta os resultados das operações e todos os elementos armazenados no vetor.
