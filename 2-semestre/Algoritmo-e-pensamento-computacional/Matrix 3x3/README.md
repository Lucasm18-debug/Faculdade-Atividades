# Atividade - Matriz 3x3

Atividade desenvolvida na disciplina de **Algoritmo e Pensamento Computacional**, utilizando a linguagem C.

## Objetivo

Criar um programa em C que utilize uma matriz 3x3 para armazenar e exibir valores inteiros.

## Requisitos da atividade

O programa deve:

- Declarar uma matriz 3x3 de números inteiros;
- Ler os valores da matriz;
- Percorrer a matriz utilizando dois laços `for`;
- Exibir os elementos da matriz na tela;
- Identificar corretamente as posições de cada elemento através dos índices de linha e coluna.

## Conceitos utilizados

- Matrizes bidimensionais;
- Índices de linha e coluna;
- Laços de repetição `for`;
- Laços `for` aninhados;
- Entrada de dados com `scanf`;
- Saída de dados com `printf`.

## Organização da matriz

A matriz possui 3 linhas e 3 colunas, totalizando 9 posições.

Os índices utilizados em C começam em 0:

```text
mat[0][0]  mat[0][1]  mat[0][2]
mat[1][0]  mat[1][1]  mat[1][2]
mat[2][0]  mat[2][1]  mat[2][2]
